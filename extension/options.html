    Site access

    Grant access to each site you want recipes to use. Under Allowed operations, choose whether workflows can use results from that site in AI prompts. You review the data before sending it to ChatGPT or copying a prompt into another chat.

      Local data sources

      Enable a source only after configuring its read-only host. Credentials stay in the host configuration. Choose separately whether workflows can include its results in AI prompts.

        Run recipes from the terminal

        Leave this off when using the browser panel, including workflows that use ChatGPT. Turn it on if a script or local agent needs to run recipes from your Linux account.

        Once the command-line helper is installed and connected, any program running as your Linux user can call recipes on sites you’ve granted access to.

        Pair a local ChatGPT helper

        On macOS or Windows, start the helper on this computer and enter its pairing code. Once paired, Browser Recipes uses this helper for ChatGPT requests.

        Developer tools

        Draft execution can change the selected site. Use a test tab when developing recipes.
